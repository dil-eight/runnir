# Compatibility Test Fixtures

Fixtures live under `Fixtures/GitHub`.

Initial fixtures cover:

- Public repository decoding.
- Workflow list decoding.

Future fixtures should cover:

- Private and organization repositories.
- Disabled workflows.
- Run status variations.
- Matrix jobs and skipped jobs.
- Expired artifacts and duplicate artifact names.
- API errors: 401, 403, 404, 422, rate limits, timeouts, and malformed responses.
